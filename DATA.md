## How to Edit

1. **Change a node**: Find the `id` in the table above, edit its details in `js/main.js` under `networkData.layers`
2. **Add a node**: Add a new object to the appropriate layer's `nodes` array, then add connections
3. **Add a connection**: Add `{ from: 'source_id', to: 'target_id', strength: 0.X }` to the `connections` array
4. **Remove a connection**: Delete the line from `connections` — the graph will find alternate paths
5. **Update stats**: Edit the stats bar in `index.html`
6. **Update presets**: Edit the preset path buttons in `index.html`
7. **Update social links**: Edit the `social-row` section in `index.html`
